## 🚀 Featured Projects

### 🛡️ [ElizaSOC](https://github.com/wilkernel/ElizaSOC) — Intelligent Security Operations Platform
A **Security Operations Center (SOC)** platform unifying **SIEM** and **SOAR** concepts into a modular architecture. Detects, correlates, and responds to threats in real time, with a live dashboard powered by Server-Sent Events.

- **Stack:** Python, Flask, scikit-learn (Isolation Forest), ClamAV, Chart.js
- **Highlights:** Clean Architecture · Ports & Adapters · TDD · ML-based behavioral analysis · automated response via iptables
- **Features:** phishing/malware detection, event correlation by IP/domain/hash, automatic quarantine, real-time log streaming
- 🎥 [Watch the demo on YouTube](https://www.youtube.com/watch?v=fmdgvTvZxDI)

### 💳 [wivipay-backend](https://github.com/wilkernel/wivipay-backend) — Payment Gateway
Back-end for a **payment gateway** with multi-provider integration (Stripe, Cielo, PayPal), OAuth2 authentication via Keycloak, and full observability.

- **Stack:** Java 17, Spring Boot 3.2, PostgreSQL, Keycloak, RabbitMQ, Docker
- **Highlights:** Strategy Pattern for providers · 70 unit tests · Prometheus + Grafana · OpenAPI 3.0 documentation
- **Features:** authorization, capture, refund, and inquiry · customer and card management · full audit trail · Flyway migrations

### 🎨 [animagic-bg-creator](https://github.com/wilkernel/animagic-bg-creator)
A **TypeScript** application for creating animated backgrounds — exploring modern UI patterns and front-end visual effects.

### 🔐 [Asset-Guardian](https://github.com/wilkernel/Asset-Guardian)
**TypeScript** project focused on digital asset protection and management.
